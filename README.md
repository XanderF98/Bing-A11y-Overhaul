
# Bing Accessibility (A11y) Overhaul

**Role:** Technical Project Manager  
**Org:** Microsoft (via Apex Systems)

## Summary
Led a platform-wide accessibility execution initiative supporting the Bing search experience.
Focused on stabilizing release quality, reducing accessibility defect intake, and improving
compliance through clearer ownership, standardized acceptance criteria, and executive visibility.

## The Challenge
- 1,000+ accessibility defects in backlog
- Inconsistent prioritization and ownership
- Undefined acceptance criteria causing regressions
- Increased release risk and delivery latency

## What I Owned
- Accessibility execution cadence and backlog health
- Cross-team coordination (Engineering, Design, QA)
- Acceptance criteria definition and enforcement
- Risk escalation and leadership reporting

## Execution Highlights
- Built controlled intake workflows in Azure DevOps
- Standardized accessibility acceptance criteria
- Led focused backlog burn-down task force
- Created Power BI dashboards for real-time visibility

## Results
- Cleared 1,000+ backlog items
- Reduced intake to <20 accessibility defects per month
- Improved feature consistency from ~70% to ~95%
- Increased release velocity by ~20%
